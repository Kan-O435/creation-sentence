# Value design for long-form note articles

## Recommended shape

Aim for 2,500–4,500 Japanese characters for a standard free article and 4,500–8,000 for a paid article, unless the promise is better met more briefly. The target is useful density, not a character count.

Use this sequence: sharp reader situation → stakes and scope → a named framework → 3–5 actionable sections → worked application → limits/when not to use → checklist/template → next action. Let the article type change the balance: a sourced experience needs more reflection and reusable tools; a research article needs sources and comparisons; a how-to needs examples and failure modes.

## Safe ways to add depth

- Turn one insight into a diagnostic checklist.
- Explain the decision criteria, not only the conclusion.
- Include a clearly marked `架空例` to demonstrate application.
- Contrast two choices and state the trade-off.
- Add failure modes, exceptions, and a minimum viable first step.
- Offer copyable prompts, worksheets, scripts, or tables that the reader can use.

## Integrity boundary

Never turn an unknown into a fact to improve drama. Do not invent romantic outcomes, revenue, credentials, testimonials, dates, screenshots, data, or quotations. A fictional example must not resemble a real person enough to imply it is their story. Cite external facts with URL and access date. Write projections as calculations with visible assumptions.
